## Hypotheses checked

- **B1** — origin numbers not re-opened. Indirect support only: PrismML's klein-4B derivative runs 512x512 in ~9.4-12 s on 17 Pro / Pro Max, i.e. same order as Imarello's 9.9 s (experimental) / 12.2 s (default). Different model (1-bit/ternary DiT), so this is a plausibility bound, not a reproduction. PrismML's statement that full-precision klein 4B does not fit an iPhone 17 Pro Max is directionally consistent with Imarello needing 4-bit and 2.6-3.5 GB. No independent memory figure. Draw Things supports the klein family but no iPhone klein timings surfaced. **Partly verified; needs-2nd-source for exact times and all memory.**
- **B2** — **partly verified for latency, unverified for memory.** See above; treat 9.4 s (Pro Max) and ~12 s (Pro) as one vendor's two figures.
- **B3** — **GPU throttling direction verified** (arXiv iPhone 16 Pro ~-50% in two iterations; different device/model/runtime-unknown). **"ANE keeps 67% after 10 min" rests on one person, one device, one run per runtime, cold start, unplugged** — single-source, self-declared caveats. **-25% timings (35/40 s vs 390 s) confirmed in dev.to text.** **TTFT Core AI ~3.1 s vs MLX ~0.2 s: NOT FOUND** in the repo README or dev.to as fetched (README's Gemma 4 E2B table reports ITL p50: LiteRT-LM 16.3 ms, MLX-Swift 20.5 ms, Core AI 21.4 ms; and notes Core AI hits an iOS KV cap of 1,024 vs the equalised 2,048 per-call budget and is jetsammed at setup). The fetch tool may have missed a table; treat the TTFT claim as unverified.
- **B4** — **decode verified** (56 Google vs 61.1 independent, +9%). **Memory disputed by metric, not by measurement**: Google 1450 MB (undefined metric) vs 497 MB jetsam-charged phys_footprint with mmap'd weights uncharged — do not average; the larger figure is the safer planning number for a per-process limit until Google's metric is known. **TTFT 0.3 s and E4B 3380 MB: no independent source.** E4B at 3380 MB peak would approach the RN app's budget; unconfirmed.
- **B5** — **unverified.** Only upstream = Apple's card (33.9 ms on iPhone 15 Pro Max ANE, F16 49.8 MB).
- **B6** — **unverified.** Vendor post, 12 months old, 2-step runs, quantisation unstated.
- **B7** — **origin verified, stale.** README rows are 2023-era (SDXL: Sept 2023, iOS 17.0.2). No iPhone 16/17-class Core ML/Core AI SD number found in the README or in one search.
