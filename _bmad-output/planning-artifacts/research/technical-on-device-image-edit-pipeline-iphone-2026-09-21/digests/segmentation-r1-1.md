# Frente 2 — subject segmentation and matting (FINAL, round 1)

Accessed 2026-09-21. Tool-call budget spent (20 calls incl. setup); 11 distinct sources read. Coordinator correction applied mid-run: photos are general-purpose (landscapes, streets, people, selfies, food, pets, objects, sky); a bicycle is occasional, so bike/spokes is a short note and subject-agnostic segmentation is the focus. Matrix has the extra "subject-agnostic?" column.

Bottom line: Apple now ships SAM 3 as a first-party Core AI recipe (iOS 27) with a text-prompt Swift API — the only prompt-driven route with an official on-device path. But the iOS variant is a 336 px "lite" export, and I found **no iPhone latency/RAM number for it anywhere**. Vision's foreground-instance mask is the prompt-free, zero-weight, subject-agnostic option, but its edge quality, rider+bike grouping, latency and no-subject behaviour are unevidenced. RMBG-2.0 is non-commercial (CC BY-NC 4.0) — a publishing blocker.

## Answers to the brief's questions (short)
- **Q1 Vision.** Class-agnostic foreground instance mask exists since iOS 17, device-only. Not evidenced: bicycle + rider as one vs separate instance (only workaround known from API shape: union via `allInstances`), thin-structure quality, max input size, latency/RAM, no-subject behaviour, iOS 18/26/27 Swift-API changes. Capture-time mattes (AVPortraitEffectsMatte etc.) and PhotoKit access: **not researched** (budget). For general non-portrait photos they are unlikely to help (unverified belief).
- **Q2 SAM 3.** 848-850M params (HF says 0.9B); ~430-623 MB as Core AI asset; text-prompt only in Apple's recipe; iOS lite input 336 px; SAM License commercial-OK with redistribution + attribution-in-publication clauses and an ITAR/military exclusion. Alternatives (SAM 2/2.1, EfficientSAM, EdgeSAM, MobileSAM, FastSAM): only thin, device-unnamed numbers (F15); nothing with named iPhone and licence retrieved.
- **Q3 Matting.** RMBG-2.0 = CC BY-NC (blocker for publishing). BiRefNet Lite Core ML for iOS 17+ exists (community), CPU-only recommended, FP16 artifacts noted. BiRefNet upstream licence: not retrieved (unverified belief: MIT — **check before relying**). MODNet, ViTMatte, MatAnyone, Depth-Anything masks: not covered.
- **Q4 Failure modes.** No cyclist/bike-specific failure report found. Closest evidence: 4-bit compression lost an occluded object (F4); 336 px input makes thin structures a risk (inference); BiRefNet FP16/ANE artifacts (F17).
- **Correction (c), automatic prompts.** Ingredients exist (SAM 3 text prompts + `presence_logits` output + cached image embeddings + Qwen-class text models in Core AI). SAM 3 lite accepts only text, so a prompt must come from a fixed noun list or a caption model. A fixed probe list ("person", "dog", "bicycle"...) with `presence_logits` as the "is there a subject?" signal is the cheapest design (inference from F3/F5; not demonstrated). A caption/VLM step adds another model resident in memory; no source shows this chain on iPhone.

## Hypotheses checked
- **H1 — SAM 3 has an official export usable through Core AI on iOS: CONFIRMED, with caveats.** Apple (not Meta) publishes the recipe and runtime (F1-F3). Caveats: iOS 27 only; the iOS variant is 336 px lite; weights are gated (each builder accepts Meta's licence to export); disk 430-623 MB; **no iPhone latency/RAM/thermal number found**.
- **H2 — Vision foreground-instance mask is a viable lightweight fallback for rider + bike: PARTLY / UNVERIFIED.** Viable as a prompt-free, zero-shipped-weights, subject-agnostic fallback in principle (F12, F13), and it segments non-person objects (car example). No source addresses rider+bike grouping, edge/thin-structure quality, latency, memory or empty results. Needs a device test on real photos.
- **H3 — Prompt "person, bicycle" to SAM 3 yields a clean joint mask: NOT FOUND.** No evidence for multi-concept comma prompts. The architecture (per-prompt masks and presence logits, cheap re-prompt with cached embeddings) favours two separate prompts and a mask union (inference). At 336 px lite input spokes/frame tubes are doubtful (inference).
