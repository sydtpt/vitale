**[1]** MCP é um padrão para conectar aplicações de IA a sistemas externos — "USB-C para aplicações de IA" — com foco explícito em **clientes** (Claude Desktop, ChatGPT, Cursor, VS Code) conectando-se a servidores de terceiros. | source: https://modelcontextprotocol.io/introduction | publisher: Model Context Protocol (Anthropic) | pub_date: doc viva | accessed: 2026-08-21 | confidence: high | class: padrão arquitetural

**[2] ⭐ CRITÉRIO DE DECISÃO** — O engineering blog da Anthropic dá o critério explícito: **chamada direta de API é o padrão certo quando é "um agente falando com um serviço, ou um número pequeno de integrações que não precisam ser reusadas entre plataformas de agente"**. MCP resolve o problema M×N e existe para dar **distribuição** — alcançar múltiplos clientes diferentes. Não há menção a MCP como padrão para um app servir análise aos próprios usuários na própria UI. | source: https://claude.com/blog/building-agents-that-reach-production-systems-with-mcp | publisher: Anthropic | pub_date: não capturada no fetch | accessed: 2026-08-21 | confidence: high | class: padrão arquitetural

**[3] ⭐ POLÍTICA** — A Acceptable Use Policy da Anthropic **exclui explicitamente "wellness advice" da categoria de alto risco**.
