## Achados

**[1]** As APIs oficiais do programa em 2026 são **cinco**, não seis: Health API, Activity API, Women's Health API, Training API e Courses API. **Não existe produto oficial chamado "Wellness API"** — a cobertura de bem-estar (passos, FC, sono, estresse) está dentro da Health API. | source: https://developer.garmin.com/gc-developer-program/ (snippet indexado) + https://openwearables.io/docs/providers/garmin-api-integration | publisher: Garmin / Open Wearables | pub_date: página viva | accessed: 2026-08-21 | confidence: medium (sem fetch direto do domínio oficial) | class: landscape

**[2]** Cobertura de cada uma: Health API = métricas diárias (passos, FC, sono, estresse, composição corporal); Activity API = dados completos de 30+ tipos de atividade capturados no dispositivo; Women's Health API = ciclo/gravidez; Training API = dados e planos de treino; Courses API = rotas/percursos. | source: idem | publisher: Garmin | pub_date: n/d | accessed: 2026-08-21 | confidence: medium | class: landscape

**[3] ⭐⭐ ACHADO ELIMINATÓRIO — o programa está PAUSADO para novos pedidos desde ~abril/2026, sem data de retomada.** Funcionário da Garmin (Partner Services) respondeu em thread do fórum oficial: _"We are currently evolving and modernizing the Garmin Connect Developer Program. During this transition, we have temporarily paused the review and approval of new API access requests"_ e _"we are unable to provide a specific timeline for when new application processing will resume."_ | source: https://forums.garmin.com/apps-software/mobile-apps-web/f/garmin-connect-mobile-andriod/433735 | publisher: Garmin Forums (resposta de funcionário Garmin) | pub_date: thread ativo 2026 | accessed: 2026-08-21 | confidence: high | class: caminho fechado

## Leads

- `ghurt.org/garmin-api-for-personal-use` ("Why Garmin has no personal API") aparece repetidamente como a análise mais direta do problema — **fetch bloqueado pelo ambiente**. O título por si só já é dado: framing público de "sem API pessoal".
- `techdepot.blog/garmin-api-access-guide` bloqueado (403).
- **Coerência com a decisão:** se o caminho oficial exclui uso pessoal E está pausado para todos, o caminho não-oficial passa a ser a única via prática para um dev solo — com risco de quebra e possível violação de ToS (não verificado por este assistente; é o escopo do D2c).
- Contradição a investigar: a FAQ oficial (via snippet) usa linguagem mais branda ("stay tuned for more updates") que a resposta do funcionário no fórum ("paused… no timeline").
- **`developer.garmin.com/health-sdk/` apareceu como página separada da Health API** — pode ser caminho técnico diferente (SDK local vs API cloud). Não explorado. Vale checar para "fidelidade total".
